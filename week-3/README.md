# Week 3 – SQL JOINs

## Minu osa – tooted ja inventuur

Nädal 3 ülesandes analüüsisin UrbanStyle'i toodete müüki ja laoseisu, kasutades SQL JOIN-päringuid tabelite `products`, `sales` ja `inventory` ühendamiseks.

Leidsin, et 12 toodet ei ole kunagi müüdud ning 231 toote puhul tuleb laoseisu järgi kaaluda juurde tellimist. Lisaks analüüsisin toodete müüki kategooriate kaupa ning võrdlesin müügiinfot inventuuriandmetega. Tulemuste põhjal tasub UrbanStyle'il pöörata tähelepanu müümata toodetele ja toodetele, mille laoseis on jõudnud ümbertellimise piirini.

# Week 5 – Visualiseerimine

## Minu roll

Minu roll oli **A – tegevjuhi dashboard (Kristi vaade)**.

## Visualiseeringud

Koostasin Power BI-s UrbanStyle'i dashboardi, mis keskendub järgmistele näitajatele:

* Kogumüügitulu
* Klientide arv
* Müügitulu kasv
* Igakuise müügitulu trend

Dashboard kasutab KPI-kaarte ja joondiagrammi, et anda kiire ülevaade ettevõtte tulemustest.

## Äritõlgendus

Dashboard annab ülevaate ettevõtte kogumüügitulust, klientide arvust ja müügitulu muutumisest ajas. Müügitulu võrdlus 2023. ja 2024. aasta vahel näitab **19,08% kasvu**.

Dashboard aitab tegevjuhil hinnata, kas ettevõte kasvab, ning märgata olukordi, kus on vaja müügitulu muutusi lähemalt uurida.

## Kasutatud tööriistad

* Power BI Desktop
* Supabase
* SQL

## Disainiotsused

Kasutasin müügitulu muutumise näitamiseks joondiagrammi ning olulisemate näitajate esitamiseks KPI-kaarte. Visuaalses kujunduses kasutasin türkiissinist värvi `#009B8D`.

## Tehisintellekti kasutamine

Kasutasin tehisintellekti koostööpartnerina juhendamisel ja selgituste saamisel dashboardi loomise ajal. Visualiseeringute valikud ja lõplikud disainiotsused tegin mina.
